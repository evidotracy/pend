# Pend - Blockchain for Easy Transactions

## Overview
Pend is a simple blockchain implementation built in Rust. It allows you to create transactions and mine blocks.

## Features
- Create transactions between users
- Mine blocks to add transactions to the blockchain
- Track user balances
- Simple and easy to understand blockchain structure

## How it works
1. Create a new blockchain instance
2. Add transactions (from user to user)
3. Mine blocks to validate transactions
4. View the blockchain history

## Getting Started
To run this project, you need Rust installed on your computer.

Visit: https://www.rust-lang.org/tools/install
